## Project Overview
This project is a Python-based Object-Oriented Programming (OOP) system designed to track agricultural production, manage farm plots, and record crop yields for regional farmers. It utilizes custom classes, instance methods, class methods, and advanced Python data structures (dictionaries and tuples).

---

## Alignment with Digital Public Goods (DPG) Standards

This solution aligns with DPG principles in the following ways:
1. **Open-Source**: The source code is publicly hosted on GitHub, allowing extension officers, community members, and researchers to inspect, reuse, and improve the application.
2. **Inclusive & Accessible Design**: Features a light, text-based command-line interface that runs efficiently on basic laptops or low-cost computers without requiring specialized hardware or paid software.
3. **Privacy-Respecting**: Strictly logs general agricultural data (farm plot IDs, soil types, crop names, and tonnage yields) without storing sensitive or private personally identifiable information (PII).
4. **Modular & Reusable**: Designed using modular OOP principles, cleanly separating logic into `Farmer` and `FarmPlot` classes that can easily integrate with larger digital agricultural dashboards.
